# Supplier Sustainability Scorecard

An Excel supplier-assessment model designed to show how procurement requirements can be translated into measurable KPIs and a structured comparison.

## Business question
How can procurement teams combine sustainability requirements with operational supplier performance in a consistent assessment?

## Assessment areas
- CO₂ emissions
- Renewable energy use
- ISO 14001 certification
- Site proximity
- On-time delivery performance
- Weighted composite supplier score

## Techniques
- Weighted scoring
- Normalization
- KPI design
- Conditional formatting
- Supplier comparison

## Data note
All supplier data is illustrative sample data created for portfolio demonstration.
