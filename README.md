## Projects

### [Inventory Replenishment & Supplier Performance Tracker](projects/inventory-supplier-tracker/)
An Excel-based tool for tracking supplier order performance against demand and flagging delivery
discrepancies automatically, with a what-if scenario model for supplier delays. Built using
formulas only (SUMIFS, COUNTIFS, nested IF, conditional formatting, data validation) — no macros.

**Skills demonstrated:** data modelling, Excel formulas, supplier/vendor analysis, scenario
planning.

### [Supplier Sustainability Scorecard](projects/supplier-sustainability-scorecard/)
An Excel-based scoring model that weighs supplier emissions, renewable energy use, certification
and proximity alongside on-time delivery into one composite sourcing score with a
Preferred/Acceptable/Review recommendation.

**Skills demonstrated:** weighted scoring models, normalization, sustainability/ESG metrics,
supplier evaluation frameworks.

### Setup notes (delete this section once done)
1. Create a repo on GitHub (e.g. `portfolio`), don't initialize with a README.
2. In this folder: `git init`, `git add .`, `git commit -m "Initial portfolio"`.
3. `git remote add origin https://github.com/YOUR-USERNAME/portfolio.git`
4. `git branch -M main` then `git push -u origin main`.
5. On GitHub: Settings → Pages → Source: `main` branch, `/docs` folder → Save.
6. Your live link will be `https://YOUR-USERNAME.github.io/portfolio/` — update the CV link to
   this instead of the claude.ai artifact link.
