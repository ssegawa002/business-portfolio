Sustainability Score weights emissions intensity (35%), renewable energy use (25%), ISO 14001 certification (20%), and proximity to site (20%). Composite Sourcing Score blends that with on-time delivery performance (60/40) — many retailers and manufacturers now weigh both dimensions when deciding which suppliers to grow volume with.

Each project is a separate Excel workbook with live formulas (SUMIFS, COUNTIFS, nested IF, weighted scoring, conditional formatting), built alongside my Data Management coursework. Both are attached with my application. This page is a summary, not a data source.
